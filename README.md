# What states changed on data centers in 2026

How Pennsylvania, Virginia, Ohio, Maryland, and Georgia acted on data centers in 2026, through legislatures, governors, utility regulators, and local governments.

**Live page:** https://jphoebus.github.io/data-center-legislation-2026/

## What's here

- `index.html` — the comparison: where each state acted, a side-by-side by issue (sales tax exemptions, new taxes, grid cost allocation, siting, water, transparency), what stands out, and what to watch.
- `data-center-legislation-2026.csv` — the underlying data, one row per action, with status, date, summary, and source.

## Key findings

- **Governors moved faster than legislatures.** Four of the five governors acted outside the legislative process in 2026.
- **The exemptions survived, with strings.** No state repealed its data center sales tax exemption; states attached conditions or added costs instead.
- **Cost allocation is converging on the same tools** — size thresholds, minimum bills, long-term contracts, exit fees, and collateral — set by different bodies in each state.
